##  Student Grade Manager (Python Project)

This is a simple **Student Grade Management System** built using Python. It allows users to **add**, **view**, and **search** student records, along with calculating **average marks** and assigning **grades**.

###  Features
- This project can add new students with name, roll number, and marks.
- This project can automatically calculate average marks.
- This project can assign grades based on performance.
- This project can view all student records.
- This project can search for a student by roll number.
- This project can store data in a `students.json` file for persistence.

### How to Run
- Make sure you have **Python 3** installed.
- Open the project folder in your terminal or command prompt.
- Run the program:
   ```bash
   python student_manager.py
   
### Files Included
- student_manager.py: Main program file.
- students.json: Stores student records.
